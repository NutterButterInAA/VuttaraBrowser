### 0.3.2 highlights

- Extension Store update reliability, history, and background state improvements
- Extension Store search, filtering, sorting, and result-count controls
- Extension popup external-link and `chrome.tabs.create()` compatibility
- MissXss "Connect with Kick" compatibility repair
- Adaptive horizontal tab sizing with compact hover/focus Close Tab controls
- Preserved tab mute/unmute behavior
- Locked vertical tabs reserve page space on the left or right
- Automatic runtime version/build display on New Tab and Settings/About
- Microsoft Store package, FileVersion, and ProductVersion aligned at 0.3.2.0
- Windows App Certification Kit overall PASS with zero required failures

The direct GitHub installers are unsigned, so Windows may show an unknown-publisher or reputation warning. Verify the published SHA-256 before installing.

Microsoft Store packages are distributed and updated through Microsoft Store.
