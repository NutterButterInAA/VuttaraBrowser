# Vuttara Browser - Public Releases

This repository is the public distribution endpoint for **Vuttara Browser**.

The development source repository is private. Public users can download verified Windows releases from the **Releases** section.

### 0.3.0 highlights

- Vuttara AI, web-chat integrations, multi-tab research, screenshot/PDF AI, and local/free provider routing
- Tab preview cards and improved page/context tools
- Expanded Downloads Center with queues, priorities, speed/ETA, and SHA-256 checksums
- Stream Mode for selected live tabs
- Install Site as App and installed-web-app management
- Page translation, per-site zoom, and true monitor fullscreen video
- Performance, stability, privacy, and GitHub/Microsoft Store channel-isolation improvements

The direct GitHub installers are unsigned, so Windows may show an unknown-publisher or reputation warning. Verify the published SHA-256 before installing.

Microsoft Store packages are distributed and updated through Microsoft Store.
